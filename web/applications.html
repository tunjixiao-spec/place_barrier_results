一次实际使用流程

  1. 选对象。从完整清单或地图选择山脉。研究问题先明确是单条参考线还是复合山系。
  2. 查观察资格。同时记录可靠窗数、线长覆盖与逐窗 NA 原因。没有可靠窗口的地方先补资料；不要用零值代替。
  3. 看两主候选。分别保存 C / CB 结果与参数，观察窗口和贡献变化。不同特征维度的 JSD 不直接排名为“最优文化划分”。
  4. 写核查问题。将差异、低差异、种子敏感和资料稀疏对象并列，列出需要查的词源、方言、历史联系与山口交通资料。
  5. 回到独立资料。用有出处、适尺度、未用于调参的资料检验解释，记录吻合与不吻合；通过后才能扩展应用主张。

建议随调查清单一起交付：候选编号、对象名称、窗口号、原始参数、可靠覆盖、贡献类别、待核查问题、资料来源、相反解释。网页中的窗口清单可以作为调查起点，具体访问点位需另行安排。

横断山系示例：先拆清观察对象

旧工程配置的 9 成员为高黎贡山、怒山、云岭、沙鲁里山、大雪山、邛崃山、岷山、无量山、哀牢山。新版保留这份分组作导航，展示各成员当前 C / CB / B 的结果与覆盖；它不是已经外部核验的山系分类。

一个可执行的调查准备方案：先查看各成员的可靠覆盖与算法变化，再同时选取组成差异不同的对象，检查谷地联系、山口、聚落历史与方言资料能否解释差异。这个方案尚未执行，不能预先认定差异由山脉造成。

单条“横断山”参考线另外保留。新版没有山系合成 JSD；成员窗口可能重叠或共享来源，不能把它们当成独立重复，也不能直接拼线、平均后称为整个山系的文化屏障强度。

地名文化记录与保护调查

如果社区语义经真实人工编码与地方资料核验，可用来组织旧名、少数语言地名和地方记忆的记录工作。保护价值需要当地社区、研究者与相关专业人员共同判断；单个差异值不构成文化遗产认定。

区域文化展示与公共沟通

如果补齐有许可的语音、口述史与历史材料，可将地图、证据和地方叙述联动，形成地方文化展示。当前网页可展示分析过程，尚不能自动生成地方文化身份或可靠的词源故事。

区域联系与地形机制研究

补齐独立方言、DEM（数字高程模型）、坡度、起伏度、地貌与交通资料后，可检验山口与谷地是否对应组成变化，并与距离、聚落密度等解释比较。目前全国地形尚未就绪，不能直接支持交通选线、资源分配或区域规划决策。

应用的边界

  • 当前可描述：指定地名数据、特征表示、参考线和来源支持下，两侧组成怎样不同。131 个具名对象属于当前研究清单，不代表全国山脉已穷尽；144 条路径用于这些对象。
  • 当前未证明：差异超过充分匹配的条件随机基准、连续段具有正式显著性、社区对应真实文化类别，以及山脉造成了文化分隔。
  • 外部证据仍缺：合格独立方言确认窗口为 0，真实语义编码为 0；已有资料和编码空表不等于验证完成。全国地形目前仅有三个试点窗口。
  • 不用作自动裁决：行政边界、文化归属、遗产资格、保护级别或规划优先级不能由 JSD 排名直接决定。
  • 应用成效需另验：后续应记录使用者是否找到新的可核实材料、节省了多少调查准备时间、是否漏掉重要反例。当前没有这些实测结果。

方法与资料来源

UNGEGN（联合国地名专家组）的地名文化遗产工作包括地名记录、文化延续及田野采集等议题。这为“地名值得系统记录”提供背景，不等于本项目的文化分隔或应用效果已获验证。下列外部项目仅提供展示方法参考。

  • UNGEGN · Geographical Names as Cultural Heritage：地名文化遗产与采集工作背景。
  • Terrastories：地图与有出处的地方叙述联动。此次仅借鉴交互组织方式，没有引入其他社区的叙述资料。
  • Mapbox Storytelling：按章节组织地图与文字。此次不引入地图服务令牌或商业底图。
