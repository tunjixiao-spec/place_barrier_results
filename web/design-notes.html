交互服务于证据

设计目标是让全部对象可查、让缺失可见，并把可用的研究线索与尚未成立的解释分开。

本轮采用的技能

  • Anthropic 官方 frontend-design：先确定研究图集的视觉方向，再实现和截图检查。地图是主视觉，减少模板装饰与无意义动画。
  • Vercel 官方 web-design-guidelines：检查键盘操作、焦点、控件名称、网址状态、手机排版、减少动态效果等。
  • 本地 scientific-figure-design 与 spatial-research-rigor：区分 NA 和零值、保持图表尺度、保留全部山脉与不利结果，防止山系重复计权和因果过度解释。
  • 当前客户端可用的 Sites：读取其设计与本地预览指导；本项目继续使用用户指定的 GitHub Pages，没有迁移托管。

本轮直接读取并应用技能文档，没有安装来源不明的组件。没有访问或声称调用用户 ChatGPT 网页会话内不可见的私有技能。

四个平台的检索记录

  • GitHub：已读取 Terrastories、kepler.gl、Mapbox Storytelling 的项目说明。借鉴地图与明细联动、完整对象清单和分章节解释；没有照搬项目数据或引入其框架。
  • bilibili：已检索并读取作者演示页文字，例如 Mapbox 地图高亮选择演示、故事地图介绍。只参考“选择对象—查看明细”与地图叙述的组织方式；没有声称完整观看视频。
  • YouTube：检索到 Mapbox 官方 Make an interactive storytelling map 的标题、作者与课程描述；视频页直接获取失败。具体设计依据交叉核对其官方 GitHub 模板，没有声称观看完成。
  • 小红书：已搜索地图交互和可视化案例，未取得足以评估的具体笔记内容；不将搜索摘要、无关结果或需要登录的页面当成已验证设计案例。
